description: 当需要在项目中查找"某功能的实现/结论/规范在哪个文件"、会话收尾需要检查新增产出是否归档、或用户提到项目地图/资产索引/登记提案时加载。让 AI 按项目地图直达权威文件而不是蛮力翻文件夹，实测导航成本降低 96.7%~99.3%。注意：若项目已有自己的资产查询协议（如 AGENTS.md 中定义的 lookup 工具），以项目协议为准，本技能自动让位。关键词：找文件、该读哪个、项目地图、资产、归档、回灌、登记提案。

本技能是**薄壳**，不含实现正文。CLI 唯一权威用法来源：gov-hub 仓库（https://github.com/songzhou/gov-hub ，本地安装见 README）。

命中场景时按以下纪律执行（前提：项目已启用项目地图，即工作区存在 `gov-hub.yaml`）：

## 动手前（供给）
```bash
python <gov-hub安装路径>/govhub.py lookup <关键词> --root <工作区>
```
- 命中 → 读列出的权威文件，不蛮力翻文件夹；
- `[UNDECLARED]` → 先向用户展示 `init --explain` 说明并**询问一次**：
  同意 → `init --main <探测路径>`；拒绝/跳过 → `init --decline`，此后本项目永久静默、不得再提；
- `[MUTED]` → 用户已拒绝，静默跳过，一切按项目原有方式干活。

## 落盘后（回灌）
新增/移动了重要文件 → 在 registry.yaml 补条目 → `check` 验证（全绿才算改完）。

## 会话收尾（体检）
`status` 看四灯；缺口要么补登记要么告知用户归档；顺手 `suggest` 看有没有高频路线值得补关键词。

## 文案纪律
对用户只说"项目地图"，禁用"治理/登记表/回灌"等内部词；完整口径见仓库 `docs/UX_COPY.md`。
