# 导航成本对照实验（真实数据）

- 被测：`E:\AI_TEST\test_assets`（36 个 md 文件，登记表 167 条）
- 查询集：10 个高频关键词（取自登记表真实 keywords）
- 蛮力路径 = 目录浏览(678 字符) + 全文检索命中 + 误读候选(≤2 个) + 读目标文件
- 地图路径 = lookup 前 3 条命中 + 读同一目标文件
- 口径：两路径都含『读目标文件』，差值纯为导航成本；蛮力未计试错轮次，数字保守

注：单文件任务场景节省 9~9 成来自『不用翻』；若计入蛮力路径的试错重试、
误读后的重新定位与上下文污染导致的返工，实际差距更大——本实验不计这些。
