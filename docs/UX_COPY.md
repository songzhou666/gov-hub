# UX 文案口径（UX Copy Guideline）

> 本文件是 gov-hub 所有**面向用户文案**的唯一权威来源。
> CLI 提示、将来 DSH 插件的 description、首次运行引导、商店页、README 首屏
> 都从这里取材。改文案只改这里，各处薄壳引用，不各自发挥。

## 一、验收标准（文案也要过 DoD）

一条文案合格，当且仅当用户读完能回答：

1. **我能得到什么？**（说得出具体好处，不是功能名）
2. **它会动我的什么？**（新建/不改/不删，清楚到文件名）
3. **我怎么退出？**（一条命令或删一个文件）

答不出第 1 条 = 内部视角文案，打回重写。

## 二、措辞对照表（内部词 → 用户词）

统一用户词：**项目地图**。
术语澄清（文案中需要区分时用）：本插件是**项目的文件导航图**，不是 AI 的对话
记忆（agent memory）——地图是放在项目里、可查看可修改的普通文件，不保存对话
内容。凡可能被误解为"AI 存了你的东西"的表述一律改写。

禁止内部词出现在用户面前：

| 内部词 | 用户词 |
|---|---|
| 治理 / gov-hub 治理 | 项目地图（让 AI 按图直达） |
| 登记表 registry | 项目地图（文件本体可叫"地图文件"） |
| 登记（动词） | 标到地图上 / 归档 |
| 回灌 / 缺口扫描 | 新产出自动提醒上地图 |
| 记忆表 / 记忆 | **禁用**——与 agent memory 撞术语；本插件是项目的文件导航，不是 AI 的对话记忆 |
| scope / 范围声明 | 范围说明（AI 只在这个文件夹内活动） |
| 指纹 / stale | （不出现；表现为"配置改过，自动重新同步"） |
| 权威文件 canonical | 该读的那个文件 / 权威版本 |
| lookup / check / status | 查表 / 自检 / 体检报告 |

规则正文、AGENTS.md 薄壳、DESIGN 等面向 agent/开发者的文档不受此限。

## 三、确认关文案骨架（欢迎式）

```
👋 欢迎开场（一句话：我们做什么 + 您得到什么）
它主要解决以下常见问题：
  1. 痛点 A —— 启用后…
  2. 痛点 B —— 启用后…
  3. 痛点 C —— 启用后…
待地图完善后，您的每次对话都将：提速 / 省 tokens / 少出错 —— 用得越久收益越明显
（实测：真实项目资产区 10 个高频查询，找文件的导航成本降低 96.7%~99.3%，
单轮 10 次查询约省 6.4 万~37 万 tokens——见 bench/RESULTS.md；两路径都含读目标
文件、蛮力路径未计试错返工，口径保守。区间差异来自查询词的泛化程度）

地图不是一下子画出来的（小白版描述，确认关/文档首屏可用）：
> 这张地图不是一次画好的——您每次和 AI 协作，它都会自动变全：
> AI 查一次，就把"从您的问题出发、到哪个文件结束"这条路线记下来；
> 走过一遍的路，下次直接找过来。您不需要做任何事。
启用只需一次（约 1 分钟），我们会：1. 写 X  2. 写 Y（都是什么，一句话）
📌 请放心（三条硬边界，写进代码，不靠承诺）：只新增 / 只读本机不联网 / 缓存可删
后悔成本：删 2 个文件 = 完全卸载
暂不启用：没有任何影响
```

红线：欢迎式 ≠ 推销式。三段"请放心 / 后悔成本 / 暂不启用"**任何情况下不得删减**，
知情同意是确认关的合法前提。

## 四、三岔口提问措辞

> **要为这个项目建立项目地图吗？**（只新增 2 个文件、不联网、删掉即完全卸载）
> 1. 启用 —— 约 1 分钟，完成后 AI 每次对话检索更快、更省 tokens
> 2. 暂不启用，别再问 —— 本项目永久静默
> 3. 这次先不用 —— 不写任何文件，下次再问

## 五、追问降级协议（agent 纪律，写进将来 skill 正文）

- 用户选"这次先不用"：本次不写任何文件；**下次会话只追问一句**
  "上次问过是否建立项目地图，仍先不用吗？"——不再重发完整说明；
- 连续两次跳过后视为事实拒绝：第三次起按"暂不启用"处理（建议落 declined 标记）；
- 用户选"暂不启用"：永久静默，任何会话不得再次提起，除非用户主动询问。

## 六、静默模式与错误提示的用户语言

| 场景 | 用户看到的 |
|---|---|
| declined 后调用 | 本项目已选择不启用项目地图；想恢复随时删 gov-hub.declined 文件 |
| 未声明区 | 先展示第三节骨架，再按第四节提问 |
| check 不过 | 哪个文件对不上了（带路径和条目名），一句"补上或从地图上移除该条" |
| 缺口提醒 | "最近的新产出还没标上项目地图：xxx（日期）→ 归档或忽略" |
